# Film Lab for Lumen

Thirty hand-made looks for Develop, inspired by how film behaves rather than by any one stock. They appear in
Develop's presets in a group named *Film Lab*, and AI assistants connected to Lumen can offer them too. Each
look is a starting point: apply it, then adjust.

| Family | Looks |
|---|---|
| Warm colour negative | Golden Hour Negative, Soft Portrait Negative, Sunlit Summer, Amber Evening, Pink Blush Negative |
| Cool and green negative | Cool Street Negative, Green Shadow Stock, Overcast Teal, Winter Blue Roll |
| Slide | Saturated Slide, Deep Slide Chrome, Daylight Slide, Warm Slide |
| Faded and matte | Faded Matte Print, Dusty Pastel, Sun-bleached, Old Album Fade |
| Cinema | Teal and Amber, Night Neon, Cold Thriller, Golden Epic, Muted Drama |
| Black and white | Silver Print, Soft Mono, Deep Noir, Warm Tone Print, Cool Tone Mono |
| Cross-processed | Cross Process Green, Cross Process Magenta, Cross Process Yellow |

Presets only set what they name (Basic, Curves, HSL, Colour grading and Effects), never crop, rotation or
local masks, so a look can be applied over your own crop. *Duplicate to my presets* makes an editable copy.

The plugin has no code and asks for no permissions. MIT.
