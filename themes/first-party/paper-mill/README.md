# Paper Mill

Warm paper with the navigation along the top. A theme for Lumen on top of Paper, with ink-on-paper
colours for light and dark, square corners, and a `theme.css` that moves the sidebar into a row under
the title bar. The layout uses only Lumen's documented parts (`shell`, `sidebar`, `sidebar-item`); the
window controls, menus, dialogs and the undo toast are protected and stay where they are.

The screenshots are Lumen's Home page in the browser preview, with sample photos, taken with the theme's own checked CSS applied. One known rough edge: the label *People & Pets* is cut short in the top row.

MIT. Pack it with `node scripts/plugins/pack-theme.mjs themes/first-party/paper-mill`.
