# Nocturne

Inky violet, quiet and deep, for editing late. A theme for Lumen on top of Darkroom, with colours for
both light and dark (it opens in dark). Surfaces lean violet, the accent is a soft lilac in dark and a
deep violet in light, and every text colour passes Lumen's contrast checks.

The screenshots are Lumen's Home page in the browser preview with sample photos.

MIT. Pack it with `node scripts/plugins/pack-theme.mjs themes/first-party/nocturne`.
