# Coastline

Teal water and warm sand, with rounder corners. A theme for Lumen on top of Gallery, with colours for
light (it opens in light) and dark, rounder tiles and cards, and a wider gap between photos.

The screenshots are Lumen's Home page in the browser preview with sample photos.

MIT. Pack it with `node scripts/plugins/pack-theme.mjs themes/first-party/coastline`.
